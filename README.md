# Protein Design Challenges

I’m Yiwei Chen, and this is where I collect ideas for protein design and protein hackathons. Some entries start with a question or a constraint I’d like to explore. Others develop into proposals with explicit rules, experimental controls, and a plan for testing the results.

I’d also like to explore varying the side-chain length of noncanonical amino acids and reassigning the genetic code.

## Index

- [Zero-A Enzyme Challenge](proposals/zero-a.md) (v0.1 · Open for feedback). The cofactor carries out the chemical transformation. Residues in the catalytic pocket can help position the substrate and tune the cofactor, but they can’t carry out the chemical transformation directly. In the first proposed test, teams would use the same cofactor to design two variants and predict before testing which would favor the R product and which would favor the S product.

  Can you suggest an enzyme–cofactor system for a Zero-A pilot where cofactor loading, turnover, and stereoselectivity can be measured independently?

- [Redesign the Protein Alphabet](proposals/alphabet-redesign.md) (v0.1 · Open for feedback) asks teams to remove two canonical amino acids and design three noncanonical amino acids of their own to see whether the new alphabet can recover lost capabilities or add new ones.

  Can you suggest a model protein and a measurable function to test whether a noncanonical amino acid can restore function lost when two canonical amino acid types are removed from the design alphabet?

- [A World Without One Amino Acid](proposals/a-world-without-one-amino-acid.md) (v0.1 · Draft for review) proposes that teams remove one canonical amino acid type from a model protein and try to retain its function using the remaining 19. The first round would remove Trp and compare designs that replace only the original Trp sites with paired designs that keep those replacements and add compensatory mutations.

  Can you suggest a model protein with a well-characterized Trp site and separate readouts for function and folding or stability?
